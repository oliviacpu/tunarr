Captured on 2026-10-21 from source `f837ef4cc221aef5202c4872d00608863842127d`, using the generic seed in the isolated E2E fixture. The screenshots contain no production data. Routes below are relative to `/web`.

To recapture, follow the E2E setup in `plans/ui-waves-handoff.md`, then run `TUNARR_E2E_PORT_OFFSET=5000 pnpm exec playwright test tests/uiGallery.spec.ts --workers=1` from `e2e/`. Run this spec on its own so other tests cannot change the seeded settings or collections. Its named PNG attachments appear in `e2e/test-results/`; review them before copying each `<slug>-<width>-<theme>.png` to `docs/assets/ui-closeout/`. Copy the supplemental channel and transcode images to their matching filenames in `docs/assets/`, and use `channels-1440-light.png` for `channels-new.png`.

The development fixture includes developer-tool buttons and local version/FFmpeg details that differ from the release image. These captures verify the browser UI; they do not verify playback in external clients.

Wide tables scroll within their own containers. Full-page images retain fixed navigation at the initial viewport boundary; that navigation can cover a narrow strip of the expanded image.
