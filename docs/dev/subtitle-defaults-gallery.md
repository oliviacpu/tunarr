To recapture, follow the local E2E setup in `plans/ui-waves-handoff.md`, then run this case on its own from `e2e/`:

```sh
TUNARR_E2E_PORT_OFFSET=9000 TUNARR_S5C_CAPTURE_DIR=/tmp/tunarr-subtitle-captures pnpm exec playwright test tests/subtitleDefaults.spec.ts --grep 'global defaults and channel subtitle states' --workers=1
```

The test seeds French/Japanese global rows and English/Spanish retained custom rows, checks document width and browser health, and restores the original settings/channel after each flow. Inspect the PNGs before copying them to `docs/assets/subtitle-defaults/`. Developer-tool buttons and local version/FFmpeg details may differ from a release image. Browser evidence does not verify Apple TV or other external playback clients.
