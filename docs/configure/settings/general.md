# General

Manage web preferences, server access, logging, and backups under **Settings > General** (`/web/settings/general`). Opening Settings goes here.

Web preferences apply in this browser. The server form has its own Save and Reset changes controls. See [Logging](../system/logging.md) and [Backup & Restore](../system/backup.md) for details.

See [when settings take effect](applies-when.md) for the timing shown by settings chips.
