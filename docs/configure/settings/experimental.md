# Experimental

Try optional features and work around server issues under **Settings > Experimental** (`/web/settings/experimental`). The old `/web/settings/features` address redirects here.

This tab contains Proxy Artwork, XMLTV Credit Images, and Disable Search Snapshot in Backup. Playback options (HDR Tonemapping, Disable Vulkan, and Disable VAAPI Pad) are under **Settings > Playback**. WebVTT Sidecar Subtitles is under **Settings > Captions & audio**.

Flags set by environment variables are read-only and marked on the page. Moving a flag to another tab does not change what it does or when it applies.
