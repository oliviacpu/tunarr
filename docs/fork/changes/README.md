# Pending fork notes

A PR that is part of a parallel wave writes its note here as `<date>-<slug>.md`, in the same entry format as `FORK.md` (a `### <title> (<date>, PR #<n>)` heading, then What you saw / Cause / Fix / Tests / Upstream), so parallel PRs do not conflict on `FORK.md`. The wave's fold-in PR moves the notes into `FORK.md` and deletes them; a standalone PR still writes `FORK.md` directly.
